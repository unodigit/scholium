# 11. Glossary

| Term | Meaning |
| --- | --- |
| **Anchor, anchoring** | A public timestamp proving a record existed at a given time, planned to be written to a public blockchain every hour. Not enabled in this release, so every paper shows "anchor pending". |
| **Annotation** | A comment attached to one paragraph of one version of a paper. Press **A** on a paragraph to add one. |
| **Appeal** | A request for a panel of three peers to look again at a moderation decision. Allowed once per decision. |
| **Archive (`.car` file)** | A download holding a paper's signed records and files, or the whole server's public record, that can be checked offline. |
| **Commit (a review)** | Signing and sealing a formal review so that no one can read it until it is revealed. |
| **Consent** | Each listed author's signed agreement to appear on a version. A version is not published until every author consents. |
| **Contested** | A paper status: a reviewer judged it fundamentally flawed, or a moderator put it on hold. |
| **Correction** | A signed notice pointing out an error. Changes status to **Corrected** and shows a banner on every version. |
| **CRediT role** | A standard description of an author's contribution, such as Software or Writing – original draft. |
| **DID** | Your public identifier on Scholium, starting `did:key:`. It is derived from your signing key. |
| **Discussion** | Open, informal comments on a paper by members. Never changes status. |
| **Endorsement** | A signed statement by an experienced member that you may publish in a category. Your first one makes you an Author (tier 2). |
| **Escrow (reviewer identity)** | Your identity as an anonymous reviewer, stored encrypted so that only the integrity committee could open it in a misconduct case. |
| **Flag, report** | Telling the moderators a paper or post may break the policies. |
| **Formal review** | A structured review: six rubric scores with justifications, confidence and a recommendation. Decides the paper's status. |
| **Guardian** | One of the five people who can approve the recovery of your account. Three approvals are needed. |
| **Hold** | A moderation decision keeping a version out of listing until a problem is fixed. |
| **Listed** | Accepted by a moderator into the public catalogue: the feed, search and category pages. |
| **Node** | One Scholium server. Its **/network** page describes it. |
| **ORCID iD** | Your researcher identifier from orcid.org. Linking it moves you to tier 1 and lets you recover your account. |
| **Passkey** | The device-based sign-in (Face ID, Touch ID, Windows Hello, a security key) that unlocks your signing key. |
| **Policy clause** | One of the published moderation rules, MOD-01 to MOD-10. Every decision cites one. |
| **Pre-review (AI)** | The advisory report written by AI agents after a version is listed. |
| **Record** | A signed statement stored by Scholium: a paper version, a review, a consent, a decision and so on. |
| **Retraction** | A signed notice that a paper should no longer be relied on. Changes status to **Retracted** on every version. |
| **Reveal** | Publishing a committed review, once a second reviewer has committed or 21 days have passed. |
| **Rubric** | The six review dimensions: soundness of method, evidence for claims, reproducibility, novelty, clarity, limitations and ethics. |
| **`sch:` ID** | A paper's permanent ID, such as `sch:k3f9-q2xz-7mwd`; a version adds `/v2`. The last characters are a checksum. |
| **Status** | Preprint, Under review, Reviewed, Contested, Corrected or Retracted, computed from signed records by a fixed rule. |
| **Tier** | Your trust level, 0 (Reader) to 4 (Moderator), which decides what you can do. |
| **Tombstone** | What remains after a legal takedown: the record that the content existed and was removed, without the content. |
| **Verified** | Your browser checked the signatures, history and files, and they all match. |
| **Version** | One signed, permanent edition of a paper. New versions link to the previous one. |
| **Withdrawal** | A signed notice that the authors no longer stand behind a paper. It does not change status. |
